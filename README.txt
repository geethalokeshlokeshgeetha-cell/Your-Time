HOW IT WORKS
1. User opens the GitHub Pages site.
2. NO button moves away; it cannot be selected.
3. User clicks YES.
4. User enters date/time and place.
5. The submission is sent to the configured email through FormSubmit.
6. The same information is also saved in the visitor's browser localStorage.
7. The final "It's a date!" screen appears.

FIRST SUBMISSION
FormSubmit may send an activation/confirmation email to the receiving address the first time you use it. Check Inbox and Spam/Junk and activate the address if requested.

GITHUB
Upload index.html to your repository and enable GitHub Pages:
Settings -> Pages -> Deploy from a branch -> main -> /(root) -> Save.

IMPORTANT
This is a static website. FormSubmit is the external service that receives and forwards the form submission.
